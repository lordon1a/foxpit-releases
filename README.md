# Foxpit releases

Download builds of **Foxpit** — a 3D cockpit that shows your Claude Code, Codex, OpenCode and Antigravity agents working side by side.

Grab the latest version from **[Releases](https://github.com/lordon1a/foxpit-releases/releases/latest)**:

- **Windows:** `Foxpit-Setup-x.y.z.exe` (installer) or `Foxpit-x.y.z-portable.exe` (no install)

Foxpit updates itself from this page.

### "Windows protected your PC"

The app is not code-signed yet, so Windows SmartScreen may warn on first launch. Click **More info → Run anyway**.

This repository only hosts release files. Report problems in [Issues](https://github.com/lordon1a/foxpit-releases/issues).
