Frequently Asked Questions

Common questions about Foxpit architecture, agent compatibility, privacy guarantees, and Git worktree isolation.

Updated: October 2026 Category: Documentation
What is Foxpit?

Foxpit is a desktop application (Windows, macOS, Linux) built with Electron and Three.js. It gives developers a visual cockpit to run and monitor multiple autonomous coding agents — such as Claude Code, Codex, and OpenCode — inside real terminals. Agents are visualized in a 3D isometric office, allowing you to see who is working, waiting for approval, or stuck at a single glance.

Does Foxpit send code or telemetry to any external servers?

Not by the app. Foxpit's event hooks and terminal listeners connect to 127.0.0.1 on your machine, and the app collects no analytics. The app makes two kinds of outbound requests: signing in and checking your plan with the Foxpit account server (your email, an account id and an anonymous device hash, never code), and an update check against GitHub Releases. Keep in mind that the coding agents you run inside Foxpit still send your prompts and code to their own model providers — that is how those CLIs work.

Which coding agents and CLI tools are supported?

Foxpit currently provides one-click hook integration for Claude Code, OpenAI Codex CLI, and OpenCode. Furthermore, because terminals are emulated via node-pty and xterm, you can run any standard CLI tool, bash script, or custom agent runner inside the cockpit.

Do I need Node.js installed on my machine?

No. The "Connect All" setup reuses Foxpit's bundled Electron/Node runtime, so it configures the necessary hook scripts without needing a global Node.js installation on your operating system.

How does Git worktree isolation protect my codebase?

When running multiple AI agents in parallel, they can easily overwrite each other's changes or create merge collisions in the main directory. Foxpit leverages native git worktree functionality: each sub-agent is assigned its own directory and isolated Git branch. Once an agent finishes its task, you can review the diff and merge cleanly.

How does Foxpit alert me when an agent asks for approval?

Autonomous agents frequently pause to request confirmation before executing risky terminal commands or editing files. When this occurs, Foxpit immediately raises a visual banner in the 3D office, pulses the mascot desk, flashes the OS taskbar, and sends a system notification. Click the agent's status bubble or the summary bar to jump straight to that terminal.

How does orchestrator delegation save token quota and money?

Flagship models have strict token limits and higher pricing. Instead of letting the flagship model run slow compile commands or parse verbose test logs, Foxpit's orchestration workflow lets the lead agent assign sub-agents running cheaper models (such as a Haiku-class model, a free OpenCode model, or DeepSeek) inside optional worktrees. Because you pick each mascot's driver and model, you can keep expensive quota for planning and review.

How does Foxpit handle updates?

Foxpit features built-in auto-updates backed by GitHub Releases. When a new stable version is published, Foxpit can download and apply the update seamlessly without requiring manual re-installation.

Do I need an account?

Yes, a free one. Sign in with an email code, Google or GitHub to start your 3-day free trial. No card needed. Your account only holds your email and plan; your code stays on your computer.

What happens after the 3-day trial?

You will need Foxpit Pro to keep using the app. Pro is not open yet: until it is, Foxpit keeps working after your trial and we will email you when Pro is available.
