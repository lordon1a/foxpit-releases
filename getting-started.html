Getting Started with Foxpit

Set up your multi-agent coding cockpit in less than five minutes. Foxpit coordinates Claude Code, Codex, and OpenCode with real terminals, automatic Git worktrees, and 3D status monitoring.

Last updated: October 2026 Reading time: 4 min App version: 0.1.0

1. Prerequisites & System Requirements

Foxpit runs as a native desktop application on modern 64-bit operating systems:

  • Operating System: Windows 10/11 x64, recent macOS, or a modern 64-bit Linux distribution.
  • Git: Git 2.30+ installed and available in your system PATH (required for Git worktree isolation).
  • AI CLI Tools: At least one CLI agent installed: Claude Code (claude), OpenAI Codex CLI, or OpenCode.
  • Node.js: Not required. Foxpit reuses its bundled Electron/Node runtime to run its hook listeners and bridge, so you do not need a system Node.js install.

2. Installation

Grab the latest pre-built package for your operating system from the releases page:

Launch the installer and open Foxpit. On first launch, the app sets up its local configuration directory and prepares the background loopback event server on 127.0.0.1.

3. One-Click Setup ("Connect All")

To mirror terminal activities to the 3D office and track permissions in real time, Foxpit uses non-intrusive local CLI hooks.

  1. Open the Settings or click Connect Agents in the header bar.
  2. Click Connect All.
  3. Foxpit automatically writes the lightweight hook scripts to your user configuration directory (e.g. ~/.claude/hooks/).

Local-Only Event Hooks: The hooks communicate over local loopback (127.0.0.1). Foxpit sends no telemetry and uploads no code. The agent CLIs you launch still talk to their own model providers, and the app checks GitHub Releases for updates.

4. Opening a Project & Spawning Agents

Click Open Repository and select your project's root folder. Foxpit scans the Git repository and initializes the team canvas.

  • Primary Orchestrator Terminal: Launch your main orchestrator (e.g., claude) in the lead terminal tab.
  • Sub-Agent Terminals: When delegating sub-tasks or running tests in parallel, click New Agent or launch from the orchestrator.
  • Automatic Git Worktree: Enable the "Run on a separate branch" option when adding an agent. Foxpit creates a linked worktree and branch so agents never collide on uncommitted files.
Foxpit Worktree Badge

5. Monitoring Agent States at a Glance

In the 3D office view, every agent sits at a desk represented by a mascot. Their visual status reflects what is happening inside the real terminal:

  • Thinking / Running: The mascot types at the keyboard, indicating active LLM processing or command execution.
  • Waiting for Approval: A bright alert flag appears above the desk, and your OS taskbar flashes. Click the agent's status bubble or the summary bar to jump straight to its terminal and approve.
  • Idle / Done: The agent has completed its task and is awaiting further instructions.
  • Stuck / Error: Red warning indicator signals a crashed command or API rate limit.
